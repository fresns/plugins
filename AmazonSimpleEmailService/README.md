# Amazon Simple Email Service

Email Sending Service Based on Amazon Simple Email Service (SES)

## Installation

- Installation with key name: `AmazonSimpleEmailService`
- Installation using command: `php artisan market:require AmazonSimpleEmailService`

## Dev Notes

### Command Word

- `sendCode`
    - Supported variable names: `{logo}` `{icon}` `{name}` `{code}` `{time}`
- `sendEmail`
